# Безопасность проекта ArcTune

> English: ArcTune drives GPU overclocking via the public Intel IGCL API. Report any
> issue that could damage hardware or bypass the project's safety limits to the
> address below. Details in русском тексте ниже.

## Ответственность

ArcTune работает с разгоном реального железа. Пишите о проблемах так:

1. **Опасность для железа / обход лимитов** (например, можно задать питание выше
   120% / 226 Вт, тронуть vBIOS или тайминги памяти) — **приватно**: откройте
   приватный security-репозиторий или напишите автору напрямую, не публикуя
   детали до исправления.
2. **Остальное** (баги, падения, неверная телеметрия, проблемы с UI) — обычным
   issue в репозитории.

## Инварианты, которые не должны нарушаться

- Обход аппаратного лимита питания (~226 Вт = 120% от 190 Вт) — **вне scope навсегда**;
- запись/модификация vBIOS — **вне scope навсегда**;
- доступ к таймингам памяти (страпы) — **вне scope навсегда**;
- любая запись настроек — только с явным подтверждением пользователя и проверкой
  min/max/step/IsSupported из IGCL;
- чтение телеметрии остаётся read-only и не создаёт второго конкурентного опроса.

Нарушение любого из этих пунктов в pull request — основание для отказа.
