# Примеры ArcTune

Скрипты для запуска из корня проекта после `pip install -e .`.

| Файл | Что делает | Риск |
|---|---|---|
| `read_telemetry.py` | проверка окружения + план чтения телеметрии | безопасно (read-only) |

Запуск:
```powershell
python examples/read_telemetry.py
```

⚠️ Примеры, меняющие настройки карты, появятся позже и будут явно помечены.
Перед любым изменением настроек — [../docs/safety.md](../docs/safety.md).
