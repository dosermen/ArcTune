# Architecture Decision Records (ADR)

ADR — короткие записки о принятых архитектурных решениях проекта ArcTune: контекст,
решение, честные последствия и рассмотренные альтернативы. Цель — чтобы через
месяцы было понятно, *почему* код устроен именно так, и какие инварианты нельзя
нарушать.

Формат каждого ADR: номер, название, статус, дата (2026), затем Контекст →
Решение → Последствия → Альтернативы. Все решения уже реализованы в коде —
это не планы.

Статусы: **Принято** — решение действует; **Отменено** — заменено новым ADR.
