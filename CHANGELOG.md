# Changelog

Все изменения проекта ArcTune документируются здесь. Формат основан на
[Keep a Changelog](https://keepachangelog.com/), версия **1.0.0**.

Стиль версий — **SemVer** (`MAJOR.MINOR.PATCH`):

- **MAJOR** — несъвместимые изменения API или архитектуры
- **MINOR** — новые фичи, обратная совместимость с прошлыми `x.y.0`
- **PATCH** — исправления ошибок, без изменения публичного интерфейса

Публичный интерфейс ArcTune: CLI-команды (`arctune *`), профили JSON
(`~/.arctune/profiles/`), журнал (`~/.arctune/logbook.jsonl`), дамп
инцидентов (`~/.arctune/incidents/`).

## [0.2.0] — 2026-11-05

### Добавлено

- **Постоянный watchdog в GUI.** `Watchdog` (аварийная температура 85 °C,
  заморозка телеметрии, TDR Event ID 4101) работает в poll-цикле воркера и
  вне авторазгона: каждое событие — одна запись в журнал (дедуп по типу,
  сброс после нормализации) и пилюля статус-бара без модального диалога
  (заморозка — warn, остальные — danger). Авто-откат OC выполняется только
  при явной опции меню «Инструменты» (`gui/safety.py`, по умолчанию
  выключен); сбой проверки не роняет опрос телеметрии.
- **Вкладка «Об устройстве» (GUI).** Четыре read-only секции — «Устройство»
  (имя, ID, драйвер, прошивка, частота/ядра), «PCIe» (Gen/ширина, пропускная
  способность, ReBAR, адрес), «Прошивка», «ECC» — и кнопка «Обновить».
  Новые `GpuContext.pci_state/firmware_info/ecc_state` и `DeviceReport`
  собирает воркер (`reload_device`, сигналы `device_info_ready` /
  `device_report_ready`): секции читаются независимо, сбой одной (ECC не
  поддерживается на consumer-картах) попадает в `errors` и не обнуляет
  остальные — как в CLI `arctune info`.
- **CSV-экспорт телеметрии из GUI.** Кнопка «Экспорт CSV…» на вкладке
  «Мониторинг»: воркер пишет буфер реплея (последние ~10 минут опроса) в CSV —
  общий формат с CLI `telemetry --csv`. Общие функции `export_telemetry` /
  `snapshot_csv_row` / `TELEMETRY_CSV_FIELDS` вынесены в `telemetry.py`,
  CLI переведён на них (дубль колонок из `cmd_telemetry` удалён), буфер
  читается новым read-only `IncidentReplay.iter_samples()`; пустой буфер —
  честное «нет данных» без модального диалога.
- **State Doctor — `arctune state` (read-only).** Сверяет фактические значения
  OC-пунктов (`tuner.current_values()`, V2 GET) с последними записями журнала
  (`Logbook.latest_values()`) с допуском ±step/2: «ожидался +160 МГц, фактически
  +0 МГц — сброшено драйвером?». Пустой журнал — не ошибка («сверять нечего»,
  exit 0); расхождение — exit 1. Версия драйвера хранится в
  `~/.arctune/driver_version` и сверяется между сессиями: смена печатает
  предупреждение «разгон мог сброситься». Модуль `state_doctor.py` — чистая
  композиция готовых модулей, ничего не пишет на карту (единственная запись —
  служебный файл версии).
- **Загрузка GPU и занятость памяти видны везде.** Источник один — IGCL
  (`ctlEngineGetActivity` → `ΔactiveTime/Δtimestamp`, `ctlMemoryGetState` →
  `used = size − free`), проверено на живой B580. CLI: `arctune telemetry --load`
  печатает «ядро N % · память X / Y ГиБ (Z %)». GUI: карточки «Загрузка» и
  «Память занято» + две серии (0…100 %) на графике вкладки «Мониторинг», ячейки
  в оверлее (макеты 1×6 / 3×2 / 2×5). Пока база дельты не накоплена (2-й тик)
  или источник недоступен — честное «—», не ноль; настройка `load_source`
  зарезервирована под `pdh`/`dxgi` (они поднимают `NotImplementedError`).
- **Тесты: 416, покрытие 81 % (branch).** Новые: расчёт
  дельты LoadMeter, ленивое создание и деградация источника в `GpuContext`,
  вывод `--load`, заполнение ячеек оверлея, пропуск None-точек на графике,
  сверка State Doctor и файл версии драйвера, CSV-форма телеметрии
  (колонки/append/буфер реплея), кнопка экспорта в GUI, вкладка
  «Об устройстве» (секции/ошибки/слот `reload_device`).

- **Интерфейс переключается на английский.** Модуль `arctuner.i18n`:
  инлайновый `tr(ru, en)`, пункт «Вид → Язык» с диалогом перезапуска;
  выбор хранится в `~/.arctune/language`, env `ARCTUNE_LANG` важнее файла.
  Переведены меню, 8 вкладок, окно, подтверждения записи и
  верхнеуровневые сообщения CLI; журнал и тексты ошибок остались
  русскими, машинные поля — английскими.
- **Запись поддерживает не только B580.** `device_profile.py` выбирает
  рамки level-1 по device_id: B580 — проверенные потолки (питание
  50..120 %, память 19..22 Гбит/с), GENERIC — min/max/step из
  `ctlOverclockGetProperties`; чужие карты помечаются «не проверено»
  в CLI и GUI. На B580 поведение не изменилось.
- **Тесты: 350, покрытие 79 % (branch).** Добавлены коды выхода CLI
  (0/1/2/130), вытеснение кольцевого буфера replay, атомарность
  журнала, локализация, профили устройств.
- **Готова инфраструктура публикации:** CI (ruff + mypy + pytest с
  покрытием + сборка CLI/GUI exe + smoke), release по тегу `v*`
  (сверка тега с `__version__`, zip-артефакты), pre-commit-хуки,
  журнал ADR (`docs/adr/`, 6 записей).

### Исправлено

- **Отсутствующая в DLL IGCL-функция даёт честный отказ вместо
  `AttributeError`.** На узких/старых драйверах часть `ctlOverclock*`-символов
  отсутствует, и safety-цепочка записи падала traceback-ом. `IgclApi._require_func`
  проверяет `loader.has()` и поднимает `IgclError(ERROR_UNSUPPORTED_FEATURE)`;
  `_ensure_waiver` при отсутствии `ctlOverclockWaiverSet` явно запрещает запись
  (`SafetyLimitError`) с объяснением, а прочие ошибки драйвера пробрасывает
  как есть — не маскирует их под «нет API». Два новых теста в
  `test_tuner_safety.py`.
- **CLI откатывает частичные записи при сбое журнала и установки вентиляторов.**
  Если журнал не записался после изменения OC, применяется попытка отката уже
  записанных параметров; если установка FIXED-скорости прерывается на одном
  вентиляторе, все затронутые вентиляторы возвращаются в авто. Результат
  отката и ошибки журнала явно сообщаются пользователю.
- **Подписи осей графиков больше не обрезаются в «…».** QtCharts по умолчанию
  (`truncateLabels=true`) заменяет текст подписи на «…», как только места не
  хватает: на сжатом графике мониторинга все три оси показывали «…» вместо
  чисел. Обрезка выключена у `LiveChart`/`VfChart`; минимум высоты графика
  (280 px, раньше 220/260/200 в разных вкладках) перенесён в классы
  графиков — ниже ~250 px Qt сжимает ось и обрезает уже заголовок оси,
  это отдельный механизм.
- **Перезапуск собранного exe больше не падает.** QProcess наследовал
  `_PYI*`-переменные, и второй инстанс стартовал из чужого `_MEIxxxx`,
  удаляемого первым при выходе → «Failed to import encodings module».
  Перезапуск идёт через `restart_env()` с вычищенным окружением.
- **Частичная запись откатывается.** Сбой на N-м пункте `set` возвращает
  уже применённые значения (обратный порядок, каждый возврат — в журнал)
  вместо смешанного неподтверждённого состояния; то же для вентиляторов
  в GUI.
- **Повторный `log --rollback` не «откатывает откат».** Поле с последней
  записью `restored=True` больше не считается целью отката.
- **CLI запускается без установленного PySide6.** `GuiExceptionHandler`
  подгружается лениво (PEP 562) — пакетный импорт GUI больше не роняет
  CLI.
- **Версия драйвера печатается целиком:** 32.0.101.9150 вместо
  «101.9150» — битовые поля major/minor/build читались неверно.
- **Фиксация вентилятора ниже 200 об/мин блокируется** до подтверждения
  (minRPM задаёт проект: поля нет в структуре IGCL).
- **Ctrl+C в CLI → exit 130**, прочие неожиданные ошибки →
  `[UNEXPECTED]` + exit 1 вместо traceback.
- **Смена языка не теряется:** после клика по языку показывается модальный
  диалог перезапуска, пункт меню переименован в нейтральное
  «Перезапустить приложение».
- **Имя устройства декодируется utf-8** вместо ascii — не-ASCII байты из
  драйвера больше не превращаются в «?».
- **Workflow CI был невалидным YAML** (двоеточие с пробелом внутри
  неправильного скаляра `name`) — GitHub Actions отверг бы файл целиком;
  экранировано, release.yml и pre-commit-конфиг прошли ту же проверку.

### Изменено

- **mypy: 62 ошибки → 0** по всем 39 файлам src/, шаг в CI; рантайм-
  поведение не менялось — только типы, isinstance-гарды и честные
  сигнатуры.
- **Версия в одном месте:** `pyproject.toml` берёт `__version__` из
  `src/arctuner/__init__.py` через dynamic; release workflow сверяет
  тег именно с ним.
- **`autofind.py` стал модулем совместимости:** `MODE_*` и
  `AutofindAbortError` канонически в `autotune/engine.py`, отсюда
  переэкспорт; старые импорты продолжают работать (защищено тестом).
- **Покрытие — часть обычного прогона pytest** (`--cov=arctuner`,
  branch) вместо ручного флага.

### Отложено

- CI и release-workflows **ни разу не выполнялись**: remote не настроен;
  первый `git tag` — после публикации репозитория.
- 8 hardware-тестов (`-m hardware`) в этой сессии не запускались —
  только `-m "not hardware"`.
- Собранные `dist/*.exe` (23.10) ждут ручной проверки переключения
  языка RU → EN → RU.

## [0.1.0] — 2026-10-20

Первый публичный релиз. Python-обёртка над публичным IGCL API для
мониторинга и разгона дискретных Intel Arc (проверено на B580).

### Добавлено

- **Ядро (читай/пиши)**
  - `ctlInit` / `ctlClose` / `ctlEnumerateDevices` / `ctlGetDeviceProperties` — инициализация сессии, перечисление GPU, свойства
  - `ctlOverclockGetProperties`, `ctlOverclockWaiverSet` — свойства OC, waiver
  - `ctlOverclockResetToDefault` — сброс к дефолту
  - `ctlOverclockReadVFCurve`, `ctlOverclockWriteCustomVFCurve` — кривая V/F (чтение и запись)
  - `ctlOverclockGpuFrequencyOffsetSetV2`, `ctlOverclockGpuMaxVoltageOffsetSetV2` — частота и напряжение ядра
  - `ctlOverclockPowerLimitSetV2`, `ctlOverclockTemperatureLimitSetV2` — лимит питания и температура
  - `ctlOverclockVramMemSpeedLimitSetV2` — лимит памяти (Гбит/с)
  - V2 Get-функции (dynamic load через `loader`) — чтение текущих значений OC

- **Телеметрия**
  - `ctlPowerTelemetryGet` — снимок датчиков: температура, ватты, активность
  - Ватты из энергосчётчиков (`gpuEnergyCounter`/`totalCardEnergyCounter`), ΔE/Δt
  - Ватты памяти (`vramEnergyCounter`)
  - VR-фазы (gpuVrTemp, vramVrTemp, saVrTemp)
  - Пропускная способность памяти (vramReadBandwidth / vramWriteBandwidth)
  - Надбавка напряжения (gpuOverVoltagePercent)

- **Вентиляторы**
  - `ctlEnumFans`, `ctlFanGetProperties` — свойства вентиляторов (RPM, maxRPM, canControl)
  - `ctlFanGetState`, `ctlFanSetFixedSpeedMode` — чтение/запись RPM
  - `ctlFanSetDefaultMode`, `ctlFanGetConfig` — режим авто/фикс
  - На B580: только FIXED (supportedModes=0x2), таблица temp/speed недоступна

- **PCIe / Прошивка / ECC**
  - `ctlPciGetProperties`, `ctlPciGetState` — PCIe Gen, ReBAR
  - `ctlGetFirmwareProperties` — версия firmware (UNKNOWN на B580)
  - `ctlEccGetProperties`, `ctlEccGetState` — ECC (UNSUPPORTED_FEATURE на B580)

### CLI

| Команда | Описание |
|---|---|
| `arctune doctor` | Проверка IGCL API (healthcheck) |
| `arctune telemetry` | Снимок телеметрии (+ `--watch` + `--replay`) |
| `arctune status` | Диапазоны OC + текущие значения + кривая V/F |
| `arctune set` | Запись OC-настроек (с двухуровневой проверкой) |
| `arctune vf` | Кривая V/F (чтение, CSV экспорт, запись с валидацией) |
| `arctune autofind` | Авторазгон (адаптивный спуск к стабильности) |
| `arctune fans` | Вентиляторы (чтение RPM, `--set`, возврат в авто) |
| `arctune reset` | Сброс OC или вентиляторов к дефолту |
| `arctune log` | Журнал изменений (+ `--rollback`) |
| `arctune info` | PCIe / ReBAR / firmware / ECC / режим вентиляторов |
| `arctune --version` | Версия пакета |

### GUI (PySide6, `arctune-gui`)

| Вкладка | Описание |
|---|---|
| Мониторинг | Карточки: частота, напряжение, температура, ватты, память, VR-фазы, график |
| Разгон | Спинбоксы: питание (%), частота (МГц), напряжение (%), температура (°C), память (Гбит/с) |
| Вентиляторы | RPM с читаются с карты, фиксация скорости |
| V/F | Кривая напряжение/частота (drag-редактор на графике, CSV импорт/экспорт, запись) |
| Журнал | История изменений (что было → что стало), откат к исходным значениям |
| Авторазгон | Конфигуратор поиска (шаг, min_step, max_steps, temp ceiling, external_cmd), живой график, JSON-профили |
| Оверлей | HUD поверх окон: 3 макета, выбор метрик, непрозрачность, положение (read-only) |

### Безопасность

- Двухуровневая проверка записи: жёсткие инварианты проекта + min/max/step/supported от IGCL
- Жёсткие потолки: питание ≤120% (~226 Вт), память ≤22 Гбит/с (21+ — с предупреждением)
- `ctlOverclockWaiverSet` вызывается перед записью напряжения/VF
- Подтверждение пользователя для каждой операции записи
- Журнал всех изменений в `~/.arctune/logbook.jsonl`
- Реплей инцидента: кольцевой буфер телеметрии, дамп при сбросе счётчиков

### Известные ограничения B580

- `vramVoltageOffset` / `vramFrequencyOffset` — unsupported (min=max=0, deprecated)
- `VFCurveVoltageLimit` / `VFCurveFrequencyLimit` — границы драйвера (400…1500 мВ / 0…4300 МГц)
- `VFCurveVoltageOffset` — min=0 (undervolt через offset невозможен на B580)
- Вентиляторы: только FIXED-режим (таблица temp/speed недоступна)
- Тройная защита: лимит питания (120%), тайминги памяти (страпы), vBIOS — вне scope навсегда

### Зависимости

- Ядро: только Python stdlib (ctypes)
- GUI: PySide6 (extra `gui`)
- Dev: pytest, ruff, mypy (extra `dev`)
- Сборка exe: PyInstaller (extra `build`)
