# ArcTune — Превью интерфейса

## Основная информация
- **Название:** ArcTune — Intel Arc B580
- **Платформа:** Windows (PySide6 / Qt6)
- **Размер окна:** 980 × 700 px
- **Тема:** Тёмная / Светлая (меню «Вид → Тема»)
- **Масштаб:** 100–200% (меню «Вид»)

---

## Вкладки

### 1. 🖥 Мониторинг (read-only)
Карточки датчиков (MetricCard) с цветовыми маркерами и живым графиком:

**Карточки строки 1 — Ядро:**
- **Ядро** — МГц (маркер: синяя частота)
- **Напряжение** — В (маркер: серый)
- **Температура** — °C (маркер: красный)
- **Питание** — % / Вт (маркер: оранжевый)

**Карточки строки 2 — Память:**
- **Память** — Гбит/с (маркер: синий)
- **Память, V** — В (маркер: серый)
- **Память, T** — °C (маркер: красный)
- **Память, Вт** — Вт (маркер: оранжевый)

**Карточки строки 3 — Фазы и активность:**
- **Активность** — с (секунды)
- **VR ядра** — °C (зелёный)
- **VR памяти** — °C (зелёный)
- **VR SA** — °C (зелёный)

**Нижняя часть:**
- Текст «Ограничение: Power Limited / Нет» — что мешает карте держать частоту
- Подсказка: «Наведите на карточку — подсказка; клик — подробное окно»
- **График (LiveChart):** 5-минутное окно, три линии:
  - Температура (°C) и Мощность (%) — левая ось 0–100
  - Частота ядра (МГц) — правая ось 0–3300

---

### 2. 🔥 Разгон (запись)
Сетка 6 колонок × 5 строк (IGCL ctlOverclock properties):

| Колонка | Содержание |
|---|---|
| Имя | Название пункта |
| Диапазон | min…max из IGCL |
| Значение | QDoubleSpinBox (шаг из IGCL) |
| Единица | % / °C* / МГц / Гбит/с |
| Сейчас | Текущее значение |
| Кнопка | «Применить…» (вызывает confirm_write) |

**Пункты:**
1. **Лимит питания** — 0…120% (потолок проекта: 120% = 226 Вт, аппаратный)
2. **Смещение частоты ядра** — МГц
3. **Смещение напряжения** — % (только ПЛЮС; минус — через V/F)
4. **Лимит температуры** — °C* (*дравер отдаёт %, но значения — °C)
5. **Скорость памяти** — Гбит/с (номинал 20, потолок драйвера 22)

**Кнопка «⚠️ Сбросить всё к дефолту…»** — подтверждение через confirm_write

**Жёсткие потолки проекта:**
- Питание: max 120% (обход невозможен)
- Память: max 22 Гбит/с (21 работает, 22 — DATA_WRITE отказ)
- >20 Гбит/с — отдельное предупреждение «СВЕРХ НОМИНАЛА»

---

### 3. 🔄 Вентиляторы (Fan)
- Управление профилями вентиляторов
- Кнопки: применить, сбросить, обновить
- Состояние блокируется во время операций

---

### 4. 📈 V/F (Кривая напряжения/частоты)
- **Кривая V/F (VfChart):** график частота (МГц) по X, напряжение (мВ) по Y
- **Режимы:** Read-only (отображение) / Editable (drag-and-drop точек)
- **Жампы точек:**
  - Напряжение: VF_MIN_VOLTAGE_MV … VF_MAX_VOLTAGE_MV
  - Частота: VF_MIN_FREQ_MHZ … VF_MAX_FREQ_MHZ
  - Монотонность: точка не может пересечь соседей по X или Y
- Экспорт кривой в CSV / импорт из CSV

---

### 5. 📋 Журнал
- Лог событий (чтение, запись, ошибки, инциденты)
- Кнопка «Rollback» — откат к последнему сохранённому состоянию
- Кнопка «Обновить»

---

### 6. ⚡ Авторазгон (AutoTune)
- Поиск оптимальной конфигурации разгона
- Запуск/стоп поиска
- Индикатор прогресса
- Отображение результатов поиска
- Живая телеметрия в реальном времени (график не блокируется)

---

## Нижняя панель (StatusBar)
- Имя устройства (например, «Intel Arc B580»)
- **Пилюля состояния** (стилизованная метка):
  - ✅ — запись прошла успешно
  - ⚠️ — ошибка чтения/записи
  - 🚨 — инцидент (дравер перезагрузился?)
- Бегущий текст для кратких сообщений

---

## Меню «Вид»
- **Масштаб 100…200%** — переключение с перезапуском
- **Тема** — Тёмная / Светлая
- **Перезапустить с новым масштабом** — рестарт с применением масштаба

---

## Индикаторы и пилюли
- Карточки имеют tooltip (наведение) и информационное окно (клик)
- Приоритет: danger > warn > ok
- Пилюля остаётся на экране до следующего события (не таймаут)
- При закрытии: «Завершение: закрываем сессию IGCL…» — окно не висит

---

## Инварианты безопасности
- НИКОГДА не обходить лимит питания 120% (226 Вт)
- НИКОГДА не модифицировать vBIOS
- НИКОГДА не трогать тайминги памяти (трайпинги)
- Любая запись — явный диалог подтверждения
- Вкладки блокируются во время операций воркера (анти-двойной клик)
